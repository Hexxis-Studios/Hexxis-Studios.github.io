# Hexxis Studios website

The public deployment of [Hexxis Studios](https://hexxis-studios.github.io/).

This repository contains generated website files and its GitHub Pages deployment workflow. The editable studio source and development history are maintained privately. Public commits represent published website updates, not development iterations.

The files in `site/` are served through GitHub Pages. Application installers and source projects remain in their own repositories, linked from the website.
